# Search and Quick Open

Two ways to find a file:

## Search field

The search field above the file tree narrows the current workspace by name, path, title, or tag. It's instant - no Enter required. Click any path segment in the breadcrumb at the top of the document to seed the search with that segment.

## Quick Open

Press **Cmd-P** (or **Ctrl-P** on Linux/Windows) for a fuzzy-match palette across **every** workspace at once. Type a few characters; pick with arrow keys + Enter, or click. Cmd-Enter opens the result in a new tab.

## Hiding files you don't want to see

Right-click any file or folder in the tree and choose **Hide**. The pattern goes into your global clutter rules (Settings -> Explorer) and applies across all workspaces. Removing a hide-pattern brings the files back; nothing is deleted.
