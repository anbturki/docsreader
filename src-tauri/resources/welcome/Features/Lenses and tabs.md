# Lenses and tabs

The sidebar has four ways to browse the same set of files:

- **Tree** - the file structure as it sits on disk.
- **Recent** - files sorted by modification time, newest first.
- **Tags** - files grouped by their frontmatter `tags:` field.
- **Pinned** - only files you've pinned (right-click -> **Pin**).

Switch lenses with the tabs above the search field. Your choice persists.

## Tabs

Cmd-click a file to open it in a new tab. Middle-click works too. Tabs persist across app restarts - close DocsReader and your reading session comes back next time you open it.

## Outline

The outline panel on the right shows the headings of the active document. Click any heading to jump. Toggle it with the outline button in the header.
